# Commons Reasoning Network

**The federated future of intelligence.**

Commons Reasoning Network (CRN) is an open-source, AGPL 3.0+ federated intelligence infrastructure for autonomous agents, distributed compute, interoperable protocols, economic systems, and cooperative governance.

It is designed as a civilization-scale intelligence operating system rather than a traditional AI application.

---

# Core System Overview

Commons Reasoning Network is composed of multiple interoperable layers:

- Intelligence Runtime Layer  
- Autonomous Agent System  
- Universal Agent Protocol (UAP)  
- Distributed Compute Network  
- Economic Marketplace Layer  
- Identity & Trust Layer  
- Memory Sovereignty Layer  
- Simulation & Research Layer  
- Governance & Commons Foundation

- Access is free at the base layer

- Ecosystem is protected from enclosure (AGPL + commons governance)
